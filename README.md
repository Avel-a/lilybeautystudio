## Project Overview
-----------------------
Lily Beauty's Studio is a hair salon based in Port Elizabeth. The website was created to help the salon have a better online presence. It also makes it easier for customers to find information about the salon and the services that are offered. The website also allows customers to make enquiries and book appointments online.

## Website Details
## Goals
-------------------------
The goal of the website is to make it easier for customers to get information about the salon, book appointments and provide feedback online. The website can also help the salon manage customer information better.

## *Objectives*
----------------------
To promote the salon's services and prices to more people.
To allow clients to make appointments online.
To give customers information about the salon and its services.
To make the website easy to use and understand.

## ChangeLog part 2
------------------------------
I did not make changes to my Part 1 work. For Part 2, I improved my existing website based on the requirements given for the second part of the POE.

The main improvements I made were:

* Added and improved the external CSS stylesheet.
* Changed the colours to make the website look more consistent.
* Added Playfair Display for headings and Poppins for normal text.
* Improved the layout and spacing of the pages.
* Improved the navigation bar.
* Added hover effects to some of the website elements.
* Fixed the About Us section so that the text fits properly inside the container.
* Fixed the Inquiry page so that the form is wider and better positioned.
* Reduced unnecessary padding on the Inquiry page.
* Improved the size and position of images.
* Improved the footer layout.
* Moved the social-media links closer to the copyright text.
* Changed the social-media font size to match the copyright text.
* Added responsive styling for smaller screens.
* Added media queries to improve the website on different screen sizes.
* Improved the responsive navigation, images and text.
