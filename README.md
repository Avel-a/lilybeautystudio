## **Project Overview**

Lily Beauty's Studio is a hair salon based in Port Elizabeth. The website was created to help the salon have a better online presence. It also makes it easier for customers to find information about the salon and the services that are offered.

The website also allows customers to make enquiries and book appointments online.
------------------------------------------
## *Website Details*
## **Goals**

The goal of the website is to make it easier for customers to get information about the salon, book appointments and provide feedback online. The website can also help the salon manage customer information better.
------------------------------------------
## *Objectives*
To promote the salon's services and prices to more people.
To allow clients to make appointments online.
To give customers information about the salon and its services.
To make the website easy to use and understand.
--------------------------------------------

Changes Made to the Website

I made a number of changes to improve my website from Part 1.

Colours

I changed the colours of the website to make it look more consistent. I used pastel pink for some of the backgrounds and burgundy for the header and other sections. I also used darker burgundy for some headings.

Fonts

I added two fonts to the website. I used Playfair Display for the headings and Poppins for the normal text. I also changed some font sizes so that the text looks more consistent throughout the website.

Navigation

I improved the navigation bar so that the links are spaced properly and are easier to use. The navigation links include Home, About Us, Services, Gallery, Contact Us and Inquiry.

Home Page

I improved the layout of the home page. I changed the position and size of the main image and adjusted the appointment button. I also added the services section for Braiding, Hair Wash and Wig Installation.

About Us Page

I fixed the About Us section because some of the text was being cut off. I changed the size of the container and adjusted the spacing so that the text fits properly inside the white box.

Inquiry Page

I made changes to the Inquiry page because the form was too narrow and was sitting on the right side of the page. I made the form wider and reduced the padding so that it fits better on the page.

I also fixed the spacing so that the navigation, form and footer do not overlap.

Footer

I changed the footer so that the copyright text and social-media links are closer together. The social-media links are now next to the copyright text instead of being far on the right side.

I also changed the font size of the social-media links so that they match the copyright text better.

Images

I changed the sizes and positions of some of the images so that they fit better on the pages. I also made the images responsive so that they can adjust to different screen sizes.
